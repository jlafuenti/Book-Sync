# Code of Conduct

Tandem is a small project maintained in spare time. The rules are short.

## Expected

- Be respectful. Disagree with ideas, not people.
- Assume good faith. Most friction is a misunderstanding.
- Keep discussions on topic and in the open (issues and pull requests), so others can learn from them.
- Report security problems privately, as described in [SECURITY.md](SECURITY.md), not in a public issue.

## Not accepted

- Harassment, insults, discriminatory language, or personal attacks.
- Publishing someone's private information.
- Sustained disruption of discussions.

## Enforcement

Report unacceptable behaviour to **support@tandembook.com**. Reports are handled by the maintainer, kept confidential, and answered within a few days. Consequences range from a warning to removal from the project's spaces, at the maintainer's judgement.
